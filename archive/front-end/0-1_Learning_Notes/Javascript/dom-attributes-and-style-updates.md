原有关于文字、HTML 标记、表单值、图片说明、class、行内样式与 `data-*` 属性的内容已并入 [浏览器怎样查询、更新 DOM 并响应用户输入？](../../../../frontend/browser-apis/dom-manipulation-and-events.md#%E4%BF%AE%E6%94%B9%E5%86%85%E5%AE%B9%E3%80%81HTML%20%E5%B1%9E%E6%80%A7%E5%92%8C%20DOM%20%E5%AF%B9%E8%B1%A1%E5%B1%9E%E6%80%A7%E6%9C%89%E4%BD%95%E5%8C%BA%E5%88%AB%EF%BC%9F)。
