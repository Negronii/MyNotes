# LeetCode 2723：怎样组合两个 Promise 并相加？

两个输入 Promise 已经由调用方创建；本题函数负责等待它们都成功，再把各自的数字相加。关键是：完成先后不决定数值位置，`Promise.all` 按输入顺序给出结果。题目保证二者都兑现为数字；实现遇到拒绝时会把拒绝理由继续传给调用方。

## 从两个已启动的输入到和

题例用 `new Promise` 创建两个输入，其 executor（执行器）在构造时同步运行，`setTimeout` 此时分别登记；所以两个计时器在调用 `addTwoPromises` 前已经启动。一般而言，本题函数接收已创建的 Promise，不负责启动它们对应的操作。调用函数后，`Promise.all([promise1, promise2])` 同时观察两个结果；两项操作何时启动由创建 Promise 的代码决定。

较早的输入完成后，其值先按输入下标记在 `Promise.all` 内部；组合 Promise 此时仍待定，调用者还拿不到结果数组。成功时，`Promise.all` 要等两个输入都履行，然后给出一个与输入顺序一致的数组。`await` 在此期间暂停 `addTwoPromises` 的后续部分；数组就绪后，解构把第 0 项给 `val1`、第 1 项给 `val2`，函数返回二者之和。因为它是 `async` 函数，调用者收到的仍是一个 Promise，最终履行为这个和。

| 题例与输入完成顺序 | 第一次完成时保存的位置 | 两项都完成后的数组 | 组合函数的结果 |
| --- | --- | --- | --- |
| 例 1：`promise1` 在约 20 ms 给出 2；`promise2` 在约 60 ms 给出 5 | 约 20 ms：第 0 项是 2，仍需等待第 1 项 | `[2, 5]` | `2 + 5 = 7` |
| 例 2：`promise2` 在约 30 ms 给出 -12；`promise1` 在约 50 ms 给出 10 | 约 30 ms：第 1 项是 -12，仍需等待第 0 项 | `[10, -12]` | `10 + (-12) = -2` |

这些毫秒数是题目中请求的延迟，不是实时保证；需要等待较晚履行的输入后，组合 Promise 才能履行。第二例中 `promise2` 先完成，却仍写入数组第二格，所以不能按完成次序把 `-12` 当作 `val1`。

如果一个输入拒绝，`Promise.all` 会以该拒绝理由拒绝；`await` 恢复时在该位置抛出拒绝理由。本函数没有捕获它，因而 `async` 函数返回给调用者的 Promise 也以同一理由拒绝。它不会取消另一个已经启动的操作，也不会等该操作结束才报告拒绝：另一个操作仍继续运行，只是它的结果不再能使这个组合结果成功。题目约束排除了拒绝输入，因此这部分说明的是实现所用 `Promise.all` 的边界行为。

更多异步组合方式见[两个 Promise 结果怎样相加？](../../../../../../frontend/javascript/asynchronous-javascript.md#两个-promise-结果怎样相加)。

## 原题与输入约束

Given two promises `promise1` and `promise2`, return a new promise. `promise1` and `promise2` will both resolve with a number. The returned promise should resolve with the sum of the two numbers.

**Example 1:**

```
Input:
promise1 = new Promise(resolve => setTimeout(() => resolve(2), 20)),
promise2 = new Promise(resolve => setTimeout(() => resolve(5), 60))
Output: 7
Explanation: The two input promises resolve with the values of 2 and 5 respectively. The returned promise should resolve with a value of 2 + 5 = 7. The time the returned promise resolves is not judged for this problem.
```

**Example 2:**

```
Input:
promise1 = new Promise(resolve => setTimeout(() => resolve(10), 50)),
promise2 = new Promise(resolve => setTimeout(() => resolve(-12), 30))
Output: -2
Explanation: The two input promises resolve with the values of 10 and -12 respectively. The returned promise should resolve with a value of 10 + -12 = -2.
```

**Constraints:**

- `promise1` and `promise2` are promises that resolve with a number.

## Solution

```ts
type P = Promise<number>;

async function addTwoPromises(promise1: P, promise2: P): P {
  const [val1, val2] = await Promise.all([promise1, promise2]);
  return val1 + val2;
}

/**
 * addTwoPromises(Promise.resolve(2), Promise.resolve(2))
 *   .then(console.log); // 4
 */
```
