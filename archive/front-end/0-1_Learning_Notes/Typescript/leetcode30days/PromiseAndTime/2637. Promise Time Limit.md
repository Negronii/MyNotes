# [2637. Promise Time Limit](https://leetcode.com/problems/promise-time-limit/) / Promise 超时限制

Given an asynchronous function `fn` and a time `t` in milliseconds, return a new **time limited** version of the input function. `fn` takes arguments provided to the **time limited** function.

The **time limited** function should follow these rules:

- If the `fn` completes within the time limit of `t` milliseconds, the **time limited** function should resolve with the result.
- If the execution of the `fn` exceeds the time limit, the **time limited** function should reject with the string `"Time Limit Exceeded"`.

**Example 1:**

```javascript
Input:
fn = async (n) => {
    await new Promise(res => setTimeout(res, 100));
    return n * n;
}
inputs = [5]
t = 50
Output: {"rejected":"Time Limit Exceeded","time":50}
Explanation:
const limited = timeLimit(fn, t)
const start = performance.now()
let result;
try {
    const res = await limited(...inputs)
    result = {"resolved": res, "time": Math.floor(performance.now() - start)};
} catch (err) {
    result = {"rejected": err, "time": Math.floor(performance.now() - start)};
}
console.log(result) // Output
```

The provided function is set to resolve after 100ms. However, the time limit is set to 50ms. It is rejected at t=50ms because the time limit was reached.

**Example 2:**

```javascript
Input:
fn = async (n) => {
    await new Promise(res => setTimeout(res, 100));
    return n * n;
}
inputs = [5]
t = 150
Output: {"resolved":25,"time":100}
Explanation:
The function resolved 5 * 5 = 25 at t=100ms. The time limit is never reached.
```

**Example 3:**

```javascript
Input:
fn = async (a, b) => {
    await new Promise(res => setTimeout(res, 120));
    return a + b;
}
inputs = [5,10]
t = 150
Output: {"resolved":15,"time":120}
Explanation:
The function resolved 5 + 10 = 15 at t=120ms. The time limit is never reached.
```

**Example 4:**

```javascript
Input:
fn = async () => {
    throw "Error";
}
inputs = []
t = 1000
Output: {"rejected":"Error","time":0}
Explanation:
The function immediately throws an error.
```

**Constraints:**

- 0 <= `inputs.length` <= 10
- 0 <= `t` <= 1000
- `fn` returns a promise

---

## Core idea / 核心思路

Race the operation against a timer and clear the timer whenever the operation fulfills or rejects. Promise settlement is single-shot: if the timer wins, later settlement attempts are ignored. Rejecting the wrapper does not stop the underlying operation; it may continue side effects or use resources until it finishes. / 让异步操作与定时器竞争，并在操作成功或失败时清除定时器。Promise 只能完成一次：若定时器先触发，后续完成尝试会被忽略。包装 Promise 超时拒绝并不会停止底层操作；它仍可能继续产生副作用或占用资源，直到自身结束。

Timer callbacks may run later than requested. A synchronous block can run past `t`; the timer cannot run while that stack is busy, so a reaction for an already-fulfilled promise may run first and win. This is a settlement race, not a hard deadline or a way to interrupt work. If the timer wins, the underlying operation still continues because the exercise supplies no cancellation signal. / 定时器回调可能晚于请求时间执行。同步代码可能运行超过 `t`；该调用栈未结束时定时器无法执行，因此已完成 Promise 的后续任务可能先运行并获胜。这是完成结果之间的竞争，不是硬截止时间，也不能中断代码。若定时器先触发，底层操作仍会继续，因为题目没有提供取消信号。

TypeScript's explicit `this` parameter preserves receiver typing and is erased when compiled. ([Node.js timers](https://nodejs.org/api/timers.html), [ECMAScript promise settlement](https://tc39.es/ecma262/#sec-promise-objects), [TypeScript `this` parameters](https://www.typescriptlang.org/docs/handbook/2/classes.html#this-parameters)). See [asynchronous JavaScript / JavaScript 异步](../../../../../../frontend/javascript/asynchronous-javascript.md) for promise and event-loop fundamentals.

## Solution

```ts
function timeLimit<This, Args extends unknown[], Result>(
  fn: (this: This, ...args: Args) => Promise<Result>,
  t: number
): (this: This, ...args: Args) => Promise<Result> {
  return function (this: This, ...args: Args) {
    return new Promise<Result>((resolve, reject) => {
      const timeoutId = setTimeout(() => reject("Time Limit Exceeded"), t);
      const clearTimer = () => clearTimeout(timeoutId);

      try {
        Promise.resolve(fn.apply(this, args)).then(
          (value) => {
            clearTimer();
            resolve(value);
          },
          (error) => {
            clearTimer();
            reject(error);
          }
        );
      } catch (error) {
        clearTimer();
        reject(error);
      }
    });
  };
}

/**
 * const limited = timeLimit((t) => new Promise(res => setTimeout(res, t)), 100);
 * limited(150).catch(console.log) // "Time Limit Exceeded" at t=100ms
 */
```
