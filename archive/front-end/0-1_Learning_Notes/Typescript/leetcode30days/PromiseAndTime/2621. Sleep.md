# How do you represent a timer delay as a Promise? / 如何把定时器延迟包装成 Promise？ — LeetCode [2621](https://leetcode.com/problems/sleep/)

**Answer / 回答：** Resolve a Promise from a timer callback. The delay is a scheduling request, not an exact real-time guarantee. / 在定时器回调中完成 Promise；延迟是调度请求，不是精确实时保证。

**Difficulty:** Easy

Given a positive integer `millis`, write an asynchronous function that sleeps for `millis` milliseconds. It can resolve any value.

**Example 1:**

```
Input: millis = 100
Output: 100
Explanation: It should return a promise that resolves after 100ms.
let t = Date.now();
sleep(100).then(() => {
    console.log(Date.now() - t); // 100
});
```

**Example 2:**

```
Input: millis = 200
Output: 200
Explanation: It should return a promise that resolves after 200ms.
```

**Constraints:**

- 1 <= `millis` <= 1000

## Core idea / 核心思路

Wrap the timer callback in a promise and resolve when that callback runs. A timer requests a delay; it does not guarantee execution at the exact millisecond, so elapsed time may be longer. / 用 Promise 包装定时器回调，并在回调执行时完成 Promise。定时器只请求等待一段时间，并不保证恰好在指定毫秒执行，因此实际耗时可能更长。

The examples show intended delay, not a real-time timing guarantee. [Node.js timers documentation](https://nodejs.org/api/timers.html). See [asynchronous JavaScript / JavaScript 异步](../../../../../../frontend/javascript/asynchronous-javascript.md) for how timers fit into promise and event-loop processing.

## Solution

```ts
function sleep(millis: number): Promise<void> {
  return new Promise((resolve) => {
    setTimeout(resolve, millis);
  });
}

/**
 * let t = Date.now()
 * sleep(100).then(() => console.log(Date.now() - t)) // 100
 */
```
