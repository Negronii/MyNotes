# How do you return a function that ignores every argument? / 如何返回一个忽略所有参数的函数？ — LeetCode [2667](https://leetcode.com/problems/create-hello-world-function/)

**Answer / 回答：** Return a new function with a rest parameter and a constant string result. It needs no captured state. / 返回一个带剩余参数、结果恒为指定字符串的新函数；无需保存闭包状态。

Write a function `createHelloWorld`. It should return a new function that always returns `"Hello World"`.

Example 1:

```
Input: args = []
Output: "Hello World"
Explanation:
const f = createHelloWorld();
f(); // "Hello World"
```

The function returned by createHelloWorld should always return "Hello World".

Example 2:

```
Input: args = [{},null,42]
Output: "Hello World"
Explanation:
const f = createHelloWorld();
f({}, null, 42); // "Hello World"
```

Any arguments could be passed to the function but it should still always return "Hello World".

Constraints:

```
0 <= args.length <= 10
```

## Core idea / 核心思路

Return a new function that accepts any number of arguments and ignores them. No closure state is needed because every call produces the same string. / 返回一个可接收任意数量参数、但会忽略这些参数的新函数。由于每次调用都返回相同字符串，不需要闭包状态。

## Solution

```ts
function createHelloWorld() {
  return (..._args: unknown[]): string => "Hello World";
}

/**
 * const f = createHelloWorld();
 * f(); // "Hello World"
 */
```
