# 如何返回一个忽略所有实参的函数？ — LeetCode [2667](https://leetcode.com/problems/create-hello-world-function/)


Write a function `createHelloWorld`. It should return a new function that always returns `"Hello World"`.

Example 1:

```
Input: args = []
Output: "Hello World"
Explanation:
const f = createHelloWorld();
f(); // "Hello World"
```

The function returned by createHelloWorld should always return "Hello World".

Example 2:

```
Input: args = [{},null,42]
Output: "Hello World"
Explanation:
const f = createHelloWorld();
f({}, null, 42); // "Hello World"
```

Any arguments could be passed to the function but it should still always return "Hello World".

Constraints:

```
0 <= args.length <= 10
```

## 题解要点

`createHelloWorld` 每次返回一个新函数。这个函数的 rest parameter（剩余参数）把调用时的全部实参收进数组 `_args`，但函数体不读取它们，只返回固定字符串；工厂没有要保存的外层状态，所以返回函数不需要闭包变量。

这里显式写出剩余参数，也让 TypeScript 的返回类型允许调用者传入任意数量、任意类型的实参。纯 JavaScript 即使省略形参，也会接受多余实参并忽略它们；但若改成 `() => "Hello World"` 并省略剩余参数，TypeScript 会推断这是零参数函数，调用 `f({}, null, 42)` 会报实参数量错误。

因此，`f()` 与 `f({}, null, 42)` 都返回同一个 `"Hello World"`；题目测试最多传入 10 个实参。

无状态返回函数、剩余参数和实参数量的机制见[函数变换](../../../../../../frontend/javascript/currying-and-partial-application.md)。

## Solution

```ts
function createHelloWorld() {
  return (..._args: unknown[]): string => "Hello World";
}

/**
 * const f = createHelloWorld();
 * f(); // "Hello World"
 * f({}, null, 42); // "Hello World"
 */
```
