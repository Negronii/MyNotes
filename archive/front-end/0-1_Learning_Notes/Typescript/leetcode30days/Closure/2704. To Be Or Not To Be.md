# 如何按严格相等实现断言？ — LeetCode [2704](https://leetcode.com/problems/to-be-or-not-to-be/)


Write a function `expect` that helps developers test their code. It should take in any value val and return an object with the following two functions.

- `toBe(val)` accepts another value and returns `true` if the two values `===` each other. If they are not equal, it should throw an error `"Not Equal"`.
- `notToBe(val)` accepts another value and returns `true` if the two values `!==` each other. If they are equal, it should throw an error `"Equal"`.

Example 1:

```
Input: func = () => expect(5).toBe(5)
Output: {"value": true}
Explanation: 5 === 5 so this expression returns true.
```

Example 2:

```
Input: func = () => expect(5).toBe(null)
Output: {"error": "Not Equal"}
Explanation: 5 !== null so this expression throw the error "Not Equal".
```

Example 3:

```
Input: func = () => expect(5).notToBe(null)
Output: {"value": true}
Explanation: 5 !== null so this expression returns true.
```

## 题解要点

题面中的 `Output` JSON 是判题器的展示格式：`value` 展示方法正常返回的值，`error` 展示抛出错误的消息。方法本身直接返回 `true` 或抛出 `Error`，不会返回这些 JSON 对象。

strict equality（严格相等）按题意直接比较 `val` 和方法收到的实参。两个箭头函数都从外层 `expect(val)` 读取同一个 `val`；各自的比较条件成立时返回 `true`，不成立时分别抛出题目指定的消息。`notToBe` 使用 `!==`，所以成功条件与 `toBe` 相反。

| 调用 | 比较结果 | 方法结果 |
| --- | --- | --- |
| `expect(5).toBe(5)` | `5 === 5` | 返回 `true` |
| `expect(5).toBe(null)` | `5 === null` 为 `false` | 抛出消息为 `"Not Equal"` 的错误 |
| `expect(5).notToBe(null)` | `5 !== null` | 返回 `true` |
| `expect(5).notToBe(5)` | `5 !== 5` 为 `false` | 抛出消息为 `"Equal"` 的错误 |

严格相等不会对值做类型转换。数字边界也遵循 `===`：`NaN` 与自身不相等，`-0` 与 `0` 相等；对象与函数按身份比较，因此同一对象引用相等，分别创建的两个对象不相等。

TypeScript 的 `unknown` 类型允许传入任意类型的值，`===` 和 `!==` 也能直接比较这些值。

严格相等、NaN 和对象身份见[JavaScript 类型](../../../../../../frontend/javascript/javascript-types.md)。

## Solution

```ts
type ToBeOrNotToBe = {
  toBe: (val: unknown) => boolean;
  notToBe: (val: unknown) => boolean;
};

function expect(val: unknown): ToBeOrNotToBe {
  return {
    toBe: (val2: unknown): boolean => {
      if (val === val2) return true;
      throw new Error("Not Equal");
    },
    notToBe: (val2: unknown): boolean => {
      if (val !== val2) return true;
      throw new Error("Equal");
    },
  };
}

/**
 * expect(5).toBe(5); // true
 * expect(5).notToBe(5); // throws "Equal"
 */
```
