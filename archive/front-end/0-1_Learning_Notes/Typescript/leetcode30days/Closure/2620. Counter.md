# How can a closure implement a counter? / 如何用闭包实现计数器？ — LeetCode [2620](https://leetcode.com/problems/counter/)

**Answer / 回答：** Return a function that retains the starting binding and post-increments it on each call, so the first result is the initial value. / 返回的函数保留初始绑定，并在每次调用时后置递增，因此第一次返回初始值。

Given an integer `n`, return a `counter` function. This counter function initially returns `n` and then returns 1 more than the previous value every subsequent time it is called (`n`, `n + 1`, `n + 2`, etc).

Example 1:

```
Input:
n = 10
["call","call","call"]
Output: [10,11,12]
Explanation:
counter() = 10 // The first time counter() is called, it returns n.
counter() = 11 // Returns 1 more than the previous time.
counter() = 12 // Returns 1 more than the previous time.
```

Example 2:

```
Input:
n = -2
["call","call","call","call","call"]
Output: [-2,-1,0,1,2]
Explanation: counter() initially returns -2. Then increases after each sebsequent call.
```

Constraints:

```
-1000 <= n <= 1000
0 <= calls.length <= 1000
calls[i] === "call"
```

## Core idea / 核心思路

The returned function closes over the mutable binding `n`. Post-increment returns its current value and then advances it; each call to `createCounter` creates independent state. / 返回的函数通过闭包持有可变变量 `n`。后置递增先返回当前值，再将其加一；每次调用 `createCounter` 都会创建独立状态。

See [scope and closures / 作用域与闭包](../../../../../../frontend/javascript/scope-and-closure.md) for how a closure keeps its lexical environment available.

## Solution

```ts
function createCounter(n: number): () => number {
  return function () {
    return n++;
  };
}

/**
 * const counter = createCounter(10)
 * counter() // 10
 * counter() // 11
 * counter() // 12
 */
```
