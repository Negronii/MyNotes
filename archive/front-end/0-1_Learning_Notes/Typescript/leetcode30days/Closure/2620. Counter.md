# 如何用闭包实现计数器？ — LeetCode [2620](https://leetcode.com/problems/counter/)


Given an integer `n`, return a `counter` function. This counter function initially returns `n` and then returns 1 more than the previous value every subsequent time it is called (`n`, `n + 1`, `n + 2`, etc).

Example 1:

```
Input:
n = 10
["call","call","call"]
Output: [10,11,12]
Explanation:
counter() = 10 // The first time counter() is called, it returns n.
counter() = 11 // Returns 1 more than the previous time.
counter() = 12 // Returns 1 more than the previous time.
```

Example 2:

```
Input:
n = -2
["call","call","call","call","call"]
Output: [-2,-1,0,1,2]
Explanation: counter() initially returns -2. Then increases after each sebsequent call.
```

Constraints:

```
-1000 <= n <= 1000
0 <= calls.length <= 1000
calls[i] === "call"
```

## 题解要点

`createCounter(10)` 建立绑定 `n = 10`，再返回一个能访问这个绑定的函数。closure（闭包）保留的是同一绑定，因此每次调用改变的都是下一次会读取的状态。

题目中的 `calls` 是测试器的动作列表：每个 `"call"` 都让它依次调用同一个返回函数 `counter()`，并把每次调用的返回值收集成输出数组。

每次执行 `return n++` 时，后置递增先读取并记住当前 `n` 的旧值，再把 `n + 1` 写回同一绑定；`n++` 表达式求值得到刚记住的旧值，随后 `return` 再把它作为本次函数调用的结果交给调用方。表中的“调用后 `n`”就是下一次调用的输入状态。

| 调用 | 调用前 `n` | 返回值 | 调用后 `n` |
| --- | ---: | ---: | ---: |
| 第一次 | 10 | 10 | 11 |
| 第二次 | 11 | 11 | 12 |
| 第三次 | 12 | 12 | 13 |

输入 `calls.length = 0` 时不会调用返回函数，结果为空数组 `[]`，绑定仍是初始值。另一次 `createCounter(-2)` 会创建自己的 `n`，不会改动上面的计数器。

[作用域与闭包](../../../../../../frontend/javascript/scope-and-closure.md) 解释闭包如何在外层调用结束后继续保留词法状态。

## Solution

```ts
function createCounter(n: number): () => number {
  return function () {
    return n++;
  };
}

/**
 * const counter = createCounter(10)
 * counter() // 10
 * counter() // 11
 * counter() // 12
 */
```
