# [2635. Apply Transform Over Each Element in Array](https://leetcode.com/problems/apply-transform-over-each-element-in-array/) / 转换数组中的每个元素

Given an integer array arr and a mapping function `fn`, return a new array with a transformation applied to each element.

The returned array should be created such that `returnedArray[i] = fn(arr[i], i)`.

Please solve it without the built-in Array.map method.

Example 1:

```
Input: arr = [1,2,3], fn = function plusone(n) { return n + 1; }
Output: [2,3,4]
Explanation:
const newArray = map(arr, plusone); // [2,3,4]
The function increases each value in the array by one.
```

Example 2:

```
Input: arr = [1,2,3], fn = function plusI(n, i) { return n + i; }
Output: [1,3,5]
Explanation: The function increases each value by the index it resides in.
```

Example 3:

```
Input: arr = [10,20,30], fn = function constant() { return 42; }
Output: [42,42,42]
Explanation: The function always returns 42.
```

Constraints:

- `0 <= arr.length <= 1000`
- `-10^9 <= arr[i] <= 10^9`
- `fn` returns an integer.

## Core idea / 核心思路

Allocate an output array with the input's initial length and transform each present index in place in the result. This preserves holes; `i in arr` also treats an inherited numeric property as present, as `Array.prototype.map` does. / 按输入的初始长度创建结果数组，并把每个存在索引的转换值写回相同位置，因此会保留空洞。`i in arr` 也会把原型链上的数字属性视为存在，与原生 `Array.prototype.map` 一致。

The exercise supplies dense arrays, but the loop below also follows these sparse-array semantics. ([ECMAScript `map`](https://tc39.es/ecma262/#sec-array.prototype.map), [array reference](../../../../../../frontend/javascript/arrays.md))

## Solution

```ts
function map(arr: number[], fn: (n: number, i: number) => number): number[] {
  const length = arr.length;
  const mapped = new Array<number>(length);
  for (let i = 0; i < length; i++) {
    if (!(i in arr)) continue;
    const value = arr[i];
    mapped[i] = fn(value, i);
  }
  return mapped;
}
```

**Complexity / 复杂度:** `O(n)` index checks and up to `n` callback calls; the result array has length `n`, including any holes. / 执行 `O(n)` 次索引检查，回调最多调用 `n` 次；结果数组长度为 `n`，包含可能存在的空洞。
