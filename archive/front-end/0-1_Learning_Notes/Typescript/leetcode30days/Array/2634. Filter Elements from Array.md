# 不用 Array.filter，怎样按条件保留数组元素？

本题按索引扫描数组：对访问时存在的 `arr[i]` 调用 `fn(value, i)`，并用 `Boolean(fn(value, i))` 判断回调结果是否为真；只有为真时，才把原值追加到新数组。题面输入是长度 0 到 1000、元素介于 −10^9 和 10^9 的稠密整数数组。

## 原题

Given an integer array `arr` and a filtering function `fn`, return a filtered array `filteredArr`.

The `fn` function takes one or two arguments:

- `arr[i]` - number from the `arr`
- `i` - index of `arr[i]`

`filteredArr` should only contain the elements from the `arr` for which the expression `fn(arr[i], i)` evaluates to a truthy value. A truthy value is a value where `Boolean(value)` returns `true`.

Please solve it without the built-in `Array.filter` method.

**Example 1:**

```
Input: arr = [0,10,20,30], fn = function greaterThan10(n) { return n > 10; }
Output: [20,30]
Explanation:
const newArray = filter(arr, fn); // [20, 30]
The function filters out values that are not greater than 10
```

**Example 2:**

```
Input: arr = [1,2,3], fn = function firstIndex(n, i) { return i === 0; }
Output: [1]
Explanation:
fn can also accept the index of each element
In this case, the function removes elements not at index 0
```

**Example 3:**

```
Input: arr = [-2,-1,0,1,2], fn = function plusOne(n) { return n + 1 }
Output: [-2,0,1,2]
Explanation:
Falsey values such as 0 should be filtered out
```

**Constraints:**

- `0 <= arr.length <= 1000`
- `-10^9 <= arr[i] <= 10^9`

## 每一步保持什么关系？

代码先保存进入函数时的 `length`。每轮重新检查 `i in arr`，只有索引此时存在才读取 `arr[i]` 并调用一次 `fn(value, i)`；`Boolean` 为真就把读出的原值追加到 `filteredArr`，为假则不追加。回调若改写尚未访问的位置，循环会读到改写后的值；追加到初始长度之外的元素不会进入本轮扫描。原题示例的回调不改输入，下面逐项展开第三例：

| 索引 `i` | 原值 `arr[i]` | 回调结果 → `Boolean` | 迭代后 `filteredArr` |
|---:|---:|---:|---|
| 0 | −2 | −1 → `true` | `[-2]` |
| 1 | −1 | 0 → `false` | `[-2]` |
| 2 | 0 | 1 → `true` | `[-2, 0]` |
| 3 | 1 | 2 → `true` | `[-2, 0, 1]` |
| 4 | 2 | 3 → `true` | `[-2, 0, 1, 2]` |

最终得到 `[-2, 0, 1, 2]`。这里判断的是回调结果：输入中的 `0` 因回调结果为 `1` 而保留，输入中的 `-1` 因回调结果为 `0` 而排除。

题面给的是稠密数组；`i in arr` 还说明了 JavaScript 的稀疏数组（sparse array）语义：它检查自有属性和原型链属性，只有索引在两处都不存在时才跳过。命中的值用 `push` 连续追加，所以空槽不会保留在输出中。这是本题循环对数组索引的处理方式，不是 `Array.prototype.filter` 的完整 polyfill（垫片实现）：例如原生方法还支持可选 `thisArg`、把值/索引/原数组三个参数传给回调，也可借用到类数组对象（array-like object）。结果构造则取决于接收者：当 `this` 是数组时，`ArraySpeciesCreate` 可先读取该数组的 `constructor`，再据该构造器对象上的 `Symbol.species` 选择结果构造器；接收者是非数组的类数组对象时，原生方法创建普通数组。本解法只按题目签名接收 `number[]` 和两参数回调，返回普通数组。通用的数据变换机制见[数组正文](../../../../../../frontend/javascript/arrays.md)。

## Solution

```ts
type Fn = (n: number, i: number) => unknown;

function filter(arr: number[], fn: Fn): number[] {
  const length = arr.length;
  const filteredArr: number[] = [];
  for (let i = 0; i < length; i++) {
    if (!(i in arr)) continue;
    const value = arr[i];
    if (Boolean(fn(value, i))) filteredArr.push(value);
  }
  return filteredArr;
}
```

原解法在 TypeScript 5.7.2 的 `--strict` 下检查通过。若额外开启 `noUncheckedIndexedAccess`，动态的 `i in arr` 不会让编译器把随后 `arr[i]` 自动收窄为 number，仍需在代码中表达这一已验证前提；这里保留原解法，不把该开关下的类型错误误认为运行时索引检查失效。

## 如何计算成本？

若把谓词调用视为常数成本，n 个索引共 O(n) 检查，结果含 k 个匹配值，额外空间 O(k)。回调内部若还有循环或昂贵操作，必须另算其成本。
