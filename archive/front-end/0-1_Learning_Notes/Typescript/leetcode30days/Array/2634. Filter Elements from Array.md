# [2634. Filter Elements from Array](https://leetcode.com/problems/filter-elements-from-array/) / 过滤数组元素

_Difficulty:_ Easy

Given an integer array `arr` and a filtering function `fn`, return a filtered array `filteredArr`.

The `fn` function takes one or two arguments:

- `arr[i]` - number from the `arr`
- `i` - index of `arr[i]`

`filteredArr` should only contain the elements from the `arr` for which the expression `fn(arr[i], i)` evaluates to a truthy value. A truthy value is a value where `Boolean(value)` returns `true`.

Please solve it without the built-in `Array.filter` method.

**Example 1:**

```
Input: arr = [0,10,20,30], fn = function greaterThan10(n) { return n > 10; }
Output: [20,30]
Explanation:
const newArray = filter(arr, fn); // [20, 30]
The function filters out values that are not greater than 10
```

**Example 2:**

```
Input: arr = [1,2,3], fn = function firstIndex(n, i) { return i === 0; }
Output: [1]
Explanation:
fn can also accept the index of each element
In this case, the function removes elements not at index 0
```

**Example 3:**

```
Input: arr = [-2,-1,0,1,2], fn = function plusOne(n) { return n + 1 }
Output: [-2,0,1,2]
Explanation:
Falsey values such as 0 should be filtered out
```

**Constraints:**

- `0 <= arr.length <= 1000`
- `-10^9 <= arr[i] <= 10^9`

## Core idea / 核心思路

Capture the initial length and each visited value once. A present index is one for which `i in arr` is true: this skips holes but includes inherited numeric properties, matching the relevant `Array.prototype.filter` behavior. Append the value only when the predicate is truthy. / 固定初始长度，并且每次只读取一次元素。`i in arr` 判断索引是否存在：它会跳过空洞，也会包含原型链上的数字属性，与原生 `Array.prototype.filter` 的相关行为一致。仅当谓词结果为真时才把元素追加到紧凑结果中。

LeetCode's inputs are dense integer arrays; the sparse-array detail matters when reusing the loop as a general implementation. The specification uses `HasProperty`, which includes inherited properties. ([ECMAScript `filter`](https://tc39.es/ecma262/#sec-array.prototype.filter), [array reference](../../../../../../frontend/javascript/arrays.md))

## Solution

```ts
type Fn = (n: number, i: number) => unknown;

function filter(arr: number[], fn: Fn): number[] {
  const length = arr.length;
  const filteredArr: number[] = [];
  for (let i = 0; i < length; i++) {
    if (!(i in arr)) continue;
    const value = arr[i];
    if (Boolean(fn(value, i))) filteredArr.push(value);
  }
  return filteredArr;
}
```

**Complexity / 复杂度:** `O(n)` checks for `n = arr.length`; the result uses `O(k)` space for `k` kept elements. / 对 `n = arr.length` 个索引执行 `O(n)` 次检查；结果数组占用 `O(k)` 空间，其中 `k` 是保留的元素数。
