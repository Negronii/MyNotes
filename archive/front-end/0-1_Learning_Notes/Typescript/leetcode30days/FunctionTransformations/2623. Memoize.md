# 如何按实参元组记忆化函数调用？ — LeetCode [2623](https://leetcode.com/problems/memoize/)


Given a function `fn`, return a **memoized** version of that function.

A **memoized** function is a function that will never be called twice with the same inputs. Instead it will return a cached value.

You can assume there are 3 possible input functions: `sum`, `fib`, and `factorial`.

- `sum` accepts two integers `a` and `b` and returns `a + b`.
- `fib` accepts a single integer `n` and returns `1` if `n <= 1` or `fib(n - 1) + fib(n - 2)` otherwise.
- `factorial` accepts a single integer `n` and returns `1` if `n <= 1` or `factorial(n - 1) * n` otherwise.

**Example 1:**

```
Input:
fnName = "sum"
actions = ["call","call","getCallCount","call","getCallCount"]
values = [[2,2],[2,2],[],[1,2],[]]
Output: [4,4,1,3,2]
Explanation:
const sum = (a, b) => a + b;
const memoizedSum = memoize(sum);
memoizedSum(2, 2); // "call" - returns 4. sum() was called as (2, 2) was not seen before.
memoizedSum(2, 2); // "call" - returns 4. However sum() was not called because the same inputs were seen before.
// "getCallCount" - total call count: 1
memoizedSum(1, 2); // "call" - returns 3. sum() was called as (1, 2) was not seen before.
// "getCallCount" - total call count: 2
```

**Example 2:**

```
Input:
fnName = "factorial"
actions = ["call","call","call","getCallCount","call","getCallCount"]
values = [[2],[3],[2],[],[3],[]]
Output: [2,6,2,2,6,2]
Explanation:
const factorial = (n) => (n <= 1) ? 1 : (n * factorial(n - 1));
const memoFactorial = memoize(factorial);
memoFactorial(2); // "call" - returns 2.
memoFactorial(3); // "call" - returns 6.
memoFactorial(2); // "call" - returns 2. However factorial was not called because 2 was seen before.
// "getCallCount" - total call count: 2
memoFactorial(3); // "call" - returns 6. However factorial was not called because 3 was seen before.
// "getCallCount" - total call count: 2
```

**Example 3:**

```
Input:
fnName = "fib"
actions = ["call","getCallCount"]
values = [[5],[]]
Output: [8,1]
Explanation:
fib(5) = 8 // "call"
// "getCallCount" - total call count: 1
```

**Constraints:**

- `0 <= a, b <= 10^5`
- `1 <= n <= 10`
- `1 <= actions.length <= 10^5`
- `actions.length === values.length`
- `actions[i]` is one of "call" and "getCallCount"
- `fnName` is one of "sum", "factorial" and "fib"

## 题解要点

memoization（记忆化）让包装函数先按实参找缓存，再决定是否执行原函数。题目给出的函数只接受数字实参；这里把本次完整、按位置排列的实参数组序列化成键，例如 `memoizedSum(2, 2)` 的键为 `"[2,2]"`。数组顺序和长度都保留，因此 `(3, 2)` 与 `(2, 3)` 是两个键。

题目中的 `getCallCount` 是评测器读取原函数执行次数的动作：包装函数可以被重复调用，但只有未命中缓存并进入 `fn` 才会计数；原函数内部直接递归调用自己不会经过包装层，也不计入这个数。

本题的 `args` 是数字数组，`JSON.stringify(args)` 会生成字符串键。

命中时直接返回已存的值，不再调用原函数；未命中时先执行 `fn`，正常返回后才写入缓存。以题目第一个例子为例：

| 调用 | 键 | 命中？ | 本次是否执行 `sum` | 返回值 | 累计执行次数 |
| --- | --- | --- | --- | ---: | ---: |
| `memoizedSum(2, 2)` | `"[2,2]"` | 否 | 是 | 4 | 1 |
| `memoizedSum(2, 2)` | `"[2,2]"` | 是 | 否 | 4 | 1 |
| `memoizedSum(1, 2)` | `"[1,2]"` | 否 | 是 | 3 | 2 |

所以完整动作序列的输出为 `[4, 4, 1, 3, 2]`：两个 `getCallCount` 分别读到 1 和 2。当前类型把缓存结果限制为数字；若把实现推广到允许返回 `undefined` 的函数，`Map.has` 仍能区分“键不存在”和“键存在但值为 `undefined`”。

代码先用 `map.has(key)` 确认命中，再立即读取 `map.get(key)!`。本题的 `map` 只存数字，且两步之间没有改写缓存，所以这个键已有数字值；TypeScript 的 `Map.get` 声明仍包含 `undefined`，这里的 `!` 是把该前提告诉类型检查器，不会改变运行时结果。

题目限定了 `sum`、`fib`、`factorial` 的数字参数；同一参数组对应可复用的结果。此处 `fn(...args)` 是不带接收者的调用，适合这些函数。若推广到依赖 `this`、时间或可变外部状态的函数，必须先决定接收者和状态是否属于缓存身份，以及何时失效；当前实现既不转发调用时的 `this`，键也不包含它。同步执行若抛错，会在 `map.set` 前退出，下次同键调用会重试。若把这段 JavaScript 模式用于异步函数，返回的 Promise 会立即进入缓存；后续拒绝也仍由缓存的 Promise 表示。

JSON serialization（JSON 序列化）不是通用的 JavaScript 值身份编码：数组中的 `undefined`、`null`、`NaN` 和无穷大都会变成 `null`，所以这些实参会得到相同文本；`-0` 与 `0` 也都会变成 `0`。内容可序列化成相同文本的不同对象会碰撞，循环结构会在调用 `fn` 前抛错。使用其他输入类型时，应先选能表达所需身份与顺序的键结构。

本题的数字输入序列化策略与通用记忆化边界见[函数变换](../../../../../../frontend/javascript/currying-and-partial-application.md)；缓存键存在性见[Map 与 Set](../../../../../../frontend/javascript/map-and-set.md)。

## Solutions

```ts
type Fn = (...params: number[]) => number;

function memoize(fn: Fn): Fn {
  const map = new Map<string, number>();

  return function (...args) {
    const key = JSON.stringify(args);
    if (map.has(key)) {
      return map.get(key)!;
    }
    const res = fn(...args);
    map.set(key, res);
    return res;
  };
}

/**
 * let callCount = 0;
 * const memoizedFn = memoize(function (a, b) {
 *	 callCount += 1;
 *   return a + b;
 * })
 * memoizedFn(2, 3) // 5
 * memoizedFn(2, 3) // 5
 * console.log(callCount) // 1
 */
```

**复杂度：** 在本题有界整数范围内，包含 `k` 个参数时，生成序列化键需要 `O(k)` 时间；命中缓存时不会调用 `fn`。空间随不同参数元组的数量增长。
