# [2666. Allow One Function Call](https://leetcode.com/problems/allow-one-function-call/) / 最多调用一次

Given a function `fn`, return a new function that is identical to the original function except that it ensures `fn` is called at most once.

- The first time the returned function is called, it should return the same result as `fn`.
- Every subsequent time it is called, it should return `undefined`.

**Example 1:**

```
Input: fn = (a,b,c) => (a + b + c), calls = [[1,2,3],[2,3,6]]
Output: [{"calls":1,"value":6}]
Explanation:
const onceFn = once(fn);
onceFn(1, 2, 3); // 6
onceFn(2, 3, 6); // undefined, fn was not called
```

**Example 2:**

```
Input: fn = (a,b,c) => (a * b * c), calls = [[5,7,4],[2,3,6],[4,6,8]]
Output: [{"calls":1,"value":140}]
Explanation:
const onceFn = once(fn);
onceFn(5, 7, 4); // 140
onceFn(2, 3, 6); // undefined, fn was not called
onceFn(4, 6, 8); // undefined, fn was not called
```

**Constraints:**

- `calls` is a valid JSON array
- `1 <= calls.length <= 10`
- `1 <= calls[i].length <= 100`
- `2 <= JSON.stringify(calls).length <= 1000`

## Core idea / 核心思路

The returned function closes over one `called` flag. Set it before invoking `fn`, so a thrown error still consumes the single allowed call; the first call's return value or error passes through, and later calls return `undefined`. `apply` forwards the receiver and arguments. / 返回函数通过闭包持有一个 `called` 标志。调用 `fn` 前先设置标志，因此即使第一次调用抛错，也已经用掉唯一一次机会；首次返回值或错误会原样传递，后续调用返回 `undefined`。`apply` 会转发接收者和参数。

In TypeScript, the explicit `this` parameter describes the receiver for type checking and adds no runtime argument. ([TypeScript function `this` parameters](https://www.typescriptlang.org/docs/handbook/2/functions.html#declaring-this-in-a-function), [scope and closures / 作用域与闭包](../../../../../../frontend/javascript/scope-and-closure.md))

## Solution

```ts
function once<This, Args extends unknown[], Result>(
  fn: (this: This, ...args: Args) => Result
): (this: This, ...args: Args) => Result | undefined {
  let called = false;

  return function (this: This, ...args: Args) {
    if (called) return undefined;
    called = true;
    return fn.apply(this, args);
  };
}

/**
 * let fn = (a,b,c) => (a + b + c)
 * let onceFn = once(fn)
 *
 * onceFn(1,2,3); // 6
 * onceFn(2,3,6); // returns undefined without calling fn
 */
```
