# 如何包装函数并最多调用一次？ — LeetCode [2666](https://leetcode.com/problems/allow-one-function-call/)


Given a function `fn`, return a new function that is identical to the original function except that it ensures `fn` is called at most once.

- The first time the returned function is called, it should return the same result as `fn`.
- Every subsequent time it is called, it should return `undefined`.

**Example 1:**

```
Input: fn = (a,b,c) => (a + b + c), calls = [[1,2,3],[2,3,6]]
Output: [{"calls":1,"value":6}]
Explanation:
const onceFn = once(fn);
onceFn(1, 2, 3); // 6
onceFn(2, 3, 6); // undefined, fn was not called
```

**Example 2:**

```
Input: fn = (a,b,c) => (a * b * c), calls = [[5,7,4],[2,3,6],[4,6,8]]
Output: [{"calls":1,"value":140}]
Explanation:
const onceFn = once(fn);
onceFn(5, 7, 4); // 140
onceFn(2, 3, 6); // undefined, fn was not called
onceFn(4, 6, 8); // undefined, fn was not called
```

**Constraints:**

- `calls` is a valid JSON array
- `1 <= calls.length <= 10`
- `1 <= calls[i].length <= 100`
- `2 <= JSON.stringify(calls).length <= 1000`

## 题解要点

返回函数通过 closure（闭包）保存 `called` 标志，所有后续调用共享这个标志。第一次进入包装函数时，先将标志置为 `true`，再用 `apply` 把当前接收者和全部实参交给 `fn`；之后包装函数不再调用 `fn`，而是返回 `undefined`。

题面输出中的 `calls: 1` 表示评测器统计到原函数 `fn` 实际执行了一次；之后只返回 `undefined` 的包装函数调用不会计入这个数。

| 调用路径 | 调用前标志 | `fn` 是否运行 | 包装函数结果 | 调用后标志 |
| --- | --- | --- | --- | --- |
| 首次正常返回 | `false` | 是，一次 | `fn` 的返回值 | `true` |
| 后续调用 | `true` | 否 | `undefined` | `true` |
| 首次调用时抛错 | `false` | 是，一次 | 同一个异常继续抛出 | `true` |

因此，“至多调用一次”在这份实现里限制的是尝试次数：即使第一次同步抛错，或返回的 Promise 后来被拒绝，标志也不会复位。TypeScript 签名中的显式 `this: This` 参数只描述调用约定，不会作为运行时实参传给 `fn`。

包装器的接收者转发，以及“第一次抛错也消耗机会”的策略见[函数变换](../../../../../../frontend/javascript/currying-and-partial-application.md)。

以普通、未绑定的函数 `fn` 为例，令 `obj.run = once(fn)`，再用 `obj.run()` 调用包装函数。在这个方法调用中，包装函数里的 `this` 是 `obj`；`fn.apply(this, args)` 会把这个接收者转发给 `fn`，因此 `fn` 内的 `this` 也指向 `obj`。

## Solution

```ts
function once<This, Args extends unknown[], Result>(
  fn: (this: This, ...args: Args) => Result
): (this: This, ...args: Args) => Result | undefined {
  let called = false;

  return function (this: This, ...args: Args) {
    if (called) return undefined;
    called = true;
    return fn.apply(this, args);
  };
}

/**
 * let fn = (a,b,c) => (a + b + c)
 * let onceFn = once(fn)
 *
 * onceFn(1,2,3); // 6
 * onceFn(2,3,6); // returns undefined without calling fn
 */
```
