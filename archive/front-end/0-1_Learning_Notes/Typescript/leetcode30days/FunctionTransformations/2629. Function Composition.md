# 如何从右向左组合函数？ — LeetCode [2629](https://leetcode.com/problems/function-composition/)


Given an array of functions `[f1, f2, f3, ..., fn]`, return a new function `fn` that is the **function composition** of the array of functions.

The **function composition** of `f(x), g(x), h(x)` is `fn(x) = f(g(h(x)))`.

The **function composition** of an empty list of functions is the **identity function** `f(x) = x`.

You may assume each function in the array accepts one integer as input and returns one integer as output.

**Example 1:**

```
Input: functions = [x => x + 1, x => x * x, x => 2 + x], x = 4
Output: 37
Explanation:
Evaluating from right to left ...
Starting with x = 4.
2 + (4) = 6
(6) * (6) = 36
(36) + 1 = 37
```

**Example 2:**

```
Input: functions = [x => 10 * x, x => 10 * x, x => 10 * x], x = 1
Output: 1000
Explanation:
Evaluating from right to left ...
10 * (1) = 10
10 * (10) = 100
10 * (100) = 1000
```

**Example 3:**

```
Input: functions = [], x = 42
Output: 42
Explanation:
The composition of zero functions is the identity function
```

**Constraints:**

- `-1000 <= x <= 1000`
- `0 <= functions.length <= 1000`
- All functions accept and return a single integer.

## 题解要点

调用 `compose(functions)` 只创建并返回组合函数 `composed`，不会执行数组里的函数；之后调用 `composed(x)` 才按从右向左的次序运行，并把每步输出交给下一步。

function composition（函数组合）按从右向左的次序把值交给每一步：先运行数组最后一个函数，再将结果交给它左边的函数，最终计算出 `f1(f2(...fn(x)))`。空数组不进入循环，所以直接返回输入，也就是恒等函数。

以题面第一例为例，输入 `x = 4` 的状态变化如下。每一行的输出成为下一行的输入：

| 执行次序 | 函数 | 输入 | 输出 |
| ---: | --- | ---: | ---: |
| 1 | `f3(x) = 2 + x` | 4 | 6 |
| 2 | `f2(x) = x × x` | 6 | 36 |
| 3 | `f1(x) = x + 1` | 36 | 37 |

该组合只把值传给各步骤，不转发组合函数调用时的 `this`。本题的一元整数函数不依赖接收者。若某一步同步抛错，循环会在该步退出，异常传给调用者，后续步骤不运行。类型 `F` 要求每步接收并返回 `number`；若在 JavaScript 运行时传入 Promise 步骤，这是超出当前 TypeScript 签名的泛化，组合循环会把 Promise 对象作为普通返回值传给下一步，不会等待兑现值。

从右向左的组合顺序和空列表行为见[函数变换](../../../../../../frontend/javascript/currying-and-partial-application.md)。

## Solution

```ts
type F = (x: number) => number;

function compose(functions: F[]): F {
  return function (x) {
    for (let i = functions.length - 1; i >= 0; i--) {
      const fn = functions[i];
      x = fn(x);
    }
    return x;
  };
}

/**
 * const composed = compose([x => x + 1, x => x * x, x => 2 + x])
 * composed(4) // 37
 */
```

**复杂度：** 一次组合调用正常完成时，包含 `n` 个函数就会调用 `n` 次，循环自身的开销为 `O(n)`；总耗时还包括这些函数在各自输入上的运行时间。循环只额外保存索引和当前值，额外空间为 `O(1)`，不计输入数组和各函数自己的空间。
