## Implement `LazyMan` Class

This example queues actions synchronously and starts draining them with a timer after the current JavaScript stack finishes. The delays are milliseconds for illustration; timers schedule later work and do not guarantee an exact wake-up time. The constructor retains its name parameter as instance state; this minimal version focuses on queued actions rather than printing a greeting.

```typescript
class LazyMan {
    private tasks: Array<() => void> = [];
    private readonly name: string;

    constructor(name: string) {
        this.name = name;
        setTimeout(() => this.next(), 0);
    }

    eat(food: string): this {
        this.tasks.push(() => {
            console.log(`eat ${food}`);
            this.next();
        });
        return this;
    }

    sleep(time: number): this {
        this.tasks.push(() => {
            setTimeout(() => {
                console.log(`wake up after ${time}`);
                this.next();
            }, time);
        });
        return this;
    }

    private next(): void {
        const task = this.tasks.shift();
        task?.();
    }
}

const me = new LazyMan('Alex');
me.eat('apple').sleep(1000).eat('banana').sleep(1000).eat('pear');
```

Returning `this` enables chaining. Each task calls `next` only when its work is done, so a sleep delays subsequent queued work. If asynchronous code adds actions after the initial timer has already drained an empty queue, this small exercise does not restart itself; its example queues the chain synchronously.

## Implementing a Custom EventBus

This version supports string event names, positional arguments, duplicate registrations, plain-function callbacks without a bus-bound receiver, and removing all registrations of a function with `off`. Dispatch iterates a snapshot: registrations added during an emission wait until the next one, while a listener removed with `off` during dispatch may still run if it was in the snapshot. A one-shot entry is marked consumed and removed before invocation; snapshots skip an entry already consumed by a nested emission. Listener exceptions propagate and stop the current dispatch.

### Methods
- `on(event, listener)` registers a repeatable listener.
- `once(event, listener)` registers one occurrence of a listener.
- `emit(event, ...args)` invokes listeners with positional arguments.
- `off(event, listener)` removes all registrations of that function for the event, including one-shot registrations.

### Data Structure
The event map stores entries so a one-shot registration can be marked consumed before invocation, removed from future emissions, and skipped by any snapshot already in progress; `off` still matches the original listener function.

### Implementation in TypeScript

```typescript
type Listener = (...args: any[]) => void;

type ListenerEntry = {
    listener: Listener;
    once: boolean;
    consumed: boolean;
};

class EventBus {
    private events = new Map<string, ListenerEntry[]>();

    on(event: string, listener: Listener): void {
        this.add(event, listener, false);
    }

    once(event: string, listener: Listener): void {
        this.add(event, listener, true);
    }

    emit(event: string, ...args: any[]): void {
        const entries = this.events.get(event);
        if (!entries) return;

        for (const entry of [...entries]) {
            if (entry.once) {
                if (entry.consumed) continue;
                entry.consumed = true;
                this.removeEntry(event, entry);
            }
            const listener = entry.listener;
            listener(...args);
        }
    }

    off(event: string, listener: Listener): void {
        const entries = this.events.get(event);
        if (!entries) return;

        const remaining = entries.filter(entry => entry.listener !== listener);
        if (remaining.length === 0) this.events.delete(event);
        else this.events.set(event, remaining);
    }

    private add(event: string, listener: Listener, once: boolean): void {
        const entries = this.events.get(event) ?? [];
        entries.push({ listener, once, consumed: false });
        this.events.set(event, entries);
    }

    private removeEntry(event: string, entry: ListenerEntry): void {
        const entries = this.events.get(event);
        if (!entries) return;
        const remaining = entries.filter(candidate => candidate !== entry);
        if (remaining.length === 0) this.events.delete(event);
        else this.events.set(event, remaining);
    }
}

const eventBus = new EventBus();
const clickListener = (label: string) => console.log(`clicked ${label}`);
eventBus.on('click', clickListener);
eventBus.once('hover', () => console.log('hovered'));
eventBus.emit('click', 'button'); // clicked button
eventBus.emit('hover');           // hovered
eventBus.emit('hover');           // no output
eventBus.off('click', clickListener);
eventBus.emit('click', 'button'); // no output
```

Using `Map` avoids ordinary-object key collisions such as `__proto__`. This is a small synchronous event bus, not a specification for Node's `EventEmitter` or DOM events.

## Implementing the Least Recently Used (LRU) Cache Algorithm in JavaScript

The `Map` implementation below uses `-1` for a miss, so this exercise assumes cached values do not use `-1`. Capacity must be a non-negative integer; a zero-capacity cache stores nothing. `Map` iteration follows insertion order, so deleting and reinserting a hit moves it to the most-recent end. ECMAScript requires average access times to be sublinear in collection size, not a specific O(1) implementation.

```typescript
class LRUCache {
    private cache = new Map<number, number>();

    constructor(private readonly capacity: number) {
        if (!Number.isInteger(capacity) || capacity < 0) {
            throw new RangeError('capacity must be a non-negative integer');
        }
    }

    get(key: number): number {
        if (!this.cache.has(key)) return -1;

        const value = this.cache.get(key)!;
        this.cache.delete(key);
        this.cache.set(key, value);
        return value;
    }

    put(key: number, value: number): void {
        if (this.capacity === 0) return;

        if (this.cache.has(key)) {
            this.cache.delete(key);
        } else if (this.cache.size >= this.capacity) {
            const leastRecentKey = this.cache.keys().next().value;
            if (leastRecentKey !== undefined) this.cache.delete(leastRecentKey);
        }
        this.cache.set(key, value);
    }
}

const lruCache = new LRUCache(2);
lruCache.put(1, 1);
lruCache.put(2, 2);
console.log(lruCache.get(1)); // 1; key 1 becomes most recent
lruCache.put(3, 3);           // evicts key 2
console.log(lruCache.get(2)); // -1
lruCache.put(4, 4);           // evicts key 1
console.log(lruCache.get(1)); // -1
console.log(lruCache.get(3)); // 3
console.log(lruCache.get(4)); // 4
```

## Follow-up: Implementing LRU Cache Without Map or Record

The list keeps the most recent node at `head` and the least recent at `tail`; the object dictionary maps numeric keys to nodes. The null-prototype dictionary avoids inherited property names. This version shares the same capacity and `-1` sentinel constraints as the `Map` version. The expected fast lookup relies on ordinary object property access behavior in engines; ECMAScript does not promise a formal O(1) bound.

```typescript
class ListNode {
    prev: ListNode | null = null;
    next: ListNode | null = null;

    constructor(readonly key: number, public value: number) {}
}

class LRUCache {
    private readonly hashTable: { [key: string]: ListNode } = Object.create(null);
    private head: ListNode | null = null;
    private tail: ListNode | null = null;
    private size = 0;

    constructor(private readonly capacity: number) {
        if (!Number.isInteger(capacity) || capacity < 0) {
            throw new RangeError('capacity must be a non-negative integer');
        }
    }

    get(key: number): number {
        const node = this.hashTable[key];
        if (!node) return -1;
        this.moveToHead(node);
        return node.value;
    }

    put(key: number, value: number): void {
        if (this.capacity === 0) return;

        const existing = this.hashTable[key];
        if (existing) {
            existing.value = value;
            this.moveToHead(existing);
            return;
        }

        if (this.size >= this.capacity) this.removeLRUItem();
        const node = new ListNode(key, value);
        this.hashTable[key] = node;
        this.addNode(node);
        this.size++;
    }

    private addNode(node: ListNode): void {
        node.prev = null;
        node.next = this.head;
        if (this.head) this.head.prev = node;
        this.head = node;
        if (!this.tail) this.tail = node;
    }

    private removeNode(node: ListNode): void {
        if (node.prev) node.prev.next = node.next;
        else this.head = node.next;

        if (node.next) node.next.prev = node.prev;
        else this.tail = node.prev;

        node.prev = null;
        node.next = null;
    }

    private moveToHead(node: ListNode): void {
        if (this.head === node) return;
        this.removeNode(node);
        this.addNode(node);
    }

    private removeLRUItem(): void {
        if (!this.tail) return;
        const node = this.tail;
        this.removeNode(node);
        delete this.hashTable[node.key];
        this.size--;
    }
}
```
