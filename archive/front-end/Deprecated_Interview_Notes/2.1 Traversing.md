# JavaScript Arrays: Traversal and Common Operations / JavaScript 数组：遍历与常见操作

**Core / 核心：** Choose iteration by the values and control flow you need: `forEach`, `map`, and `filter` skip sparse holes; `for...of` follows the array iterator and reads holes as `undefined`; `for...in` visits enumerable string keys. 迭代方式应匹配所需的值与控制流程：`forEach`、`map` 和 `filter` 会跳过稀疏数组空位；`for...of` 遵循数组迭代器并将空位读为 `undefined`；`for...in` 遍历可枚举字符串键。

**Key terms / 关键词：** sparse array 稀疏数组 · iterable 可迭代对象 · array index 数组索引 · SameValueZero 相同值零比较 · flatten 扁平化

## Traverse an Array: `for` vs. `forEach`

### Performance Comparison
`forEach` calls its callback for each present element, in ascending index order, and returns `undefined`. It cannot be stopped with `break` or `continue`; use a loop when early exit or custom index control matters. A `for` loop reads each index you request, so a hole is observed as `undefined` unless you check whether the index exists.

### Readability and Maintenance
Choose based on the required behavior and clarity; there is no general performance winner without measuring the actual workload.

```js
const sparse = [, 'x'];
const seen = [];
sparse.forEach((value, index) => seen.push([index, value]));
console.log(seen);              // [[1, 'x']]
console.log([...sparse]);       // [undefined, 'x'] — the array iterator visits the hole as undefined
```

## Difference between `for..in` and `for..of` loops in JavaScript. 

### For...in Loop iterates over the enumerable properties of an object
- The `for..in` loop iterates over enumerable string-keyed properties, including inherited enumerable properties.
- It is generally used for objects, where the loop iterates over the property keys of the object.
- For a dense array, it commonly yields index strings, but it also sees added enumerable properties and may see inherited ones. Do not use it when you need array values or index order.

```javascript
const arr = [10, 20, 30];
for (let i in arr) {
    console.log(i); // Output: 0, 1, 2 (indexes)
}

const str = 'abc';
for (let i in str) {
    console.log(i); // Output: 0, 1, 2 (indexes)
}

const obj = {name: 'aaa', age: 30};
for (let i in obj) {
    console.log(i); // Output: name, age (keys)
}
```

### For...of Loop iterates over the values of an iterable object
- The `for..of` loop consumes values from an iterable, such as an Array, String, Map, Set, or NodeList.
- It is used to iterate over the values in these collections.
- A plain object is not iterable unless it defines an iterator.

```javascript
const arr = [10, 20, 30];
for (let i of arr) {
    console.log(i); // Output: 10, 20, 30 (values)
}

const str = 'abc';
for (let i of str) {
    console.log(i); // Output: a, b, c (characters)
}

function fn(){
    for (let arg of arguments) {
        console.log(arg);
    }
}

fn(100, 200, 'aaa'); // Output: 100, 200, 'aaa'

const s1 = new Set([10, 20, 30]);
for (let i of s1) {
    console.log(i); // Output: 10, 20, 30 (Set values)
}

const m1 = new Map([
    ['x', 100],
    ['y', 200],
    ['z', 300]
]);
for (let [key, value] of m1) {
    console.log([key, value]); // Output: ['x', 100], ['y', 200], ['z', 300]
}
```

## Array Flattening Function in JavaScript

The examples below flatten nested arrays into a new array. The handwritten recursive loop reads every index, so holes become explicit `undefined`; `reduce` skips holes; native `flat` also skips holes in flattened levels. These examples assume an acyclic array tree.

**Recursive Approach**
```ts
function arrayFlatten(arr: any[]): any[] {
    let flattenedArray: any[] = [];
    for (let i = 0; i < arr.length; i++) {
        if (Array.isArray(arr[i])) {
            flattenedArray = flattenedArray.concat(arrayFlatten(arr[i]));
        } else {
            flattenedArray.push(arr[i]);
        }
    }
    return flattenedArray;
}
```
**Advantages**:
- Makes the depth-first recursive step explicit.
- Can be adapted to a chosen depth or element policy.

**Disadvantages**:
- Can be less efficient with very deep or very large arrays due to recursive calls.

**Functional Programming Approach**
```ts
function arrayFlatten(arr: any[]): any[]{
    return arr.reduce((prev, cur) => {
        return prev.concat(Array.isArray(cur) ? arrayFlatten(cur) : cur);
    }, []);
}
```
**Advantages**:
- Concise when the reader already understands `reduce`.

**Disadvantages**:
- Recursive, similar performance considerations as the recursive approach.

**Repeated One-Level Approach**
```ts
function arrayFlatten(arr: any[]): any[] {
    while (arr.some(Array.isArray)) {
        arr = [].concat(...arr);
    }
    return arr;
}
```
**Advantages**:
- Avoids recursive calls for ordinary nested input.

**Limitations**:
- Repeatedly copies the array, can be costly, and spreading a very wide array as function arguments can hit an engine limit. Spreading the current outer array materializes its holes as `undefined`, while `concat` preserves holes in nested arrays it flattens one level; for example, `[,[,1]]` becomes `[undefined, , 1]` on its first pass. If the loop finds no nested array, holes remaining in the current array stay holes. Cyclic arrays are unsupported.

**Native `flat` Method (ES2019)**
```ts
function arrayFlatten(arr: any[]): any[] {
    return arr.flat(Infinity);
}
```
**Advantages**:
- Concise, with the flattening depth expressed directly by the API.

**Limitations**:
- Older runtimes may need a compatible implementation; the method is part of ECMAScript 2019, not ES6.

## Remove Duplicate Values from an Array

### 1. Using a Set
`Set` uses SameValueZero equality, keeps the first occurrence, and preserves insertion order. Objects are deduplicated by identity, not by matching fields.

**Example Code**:
```typescript
function removeDuplicates<T>(arr: T[]): T[] {
  return [...new Set(arr)];
}
```
**Cost:** O(n) additional space. ECMAScript requires average Set access to be sublinear, but does not promise O(1) operations or a fixed runtime.

### 2.1 Using Filter with Index Check
This keeps the first occurrence for ordinary values, but `indexOf` uses strict equality, so a `NaN` value is never found, including at its own index; this filter therefore drops every `NaN`. `filter` also skips holes in a sparse array.

**Example Code**:
```typescript
function removeDuplicates<T>(arr: T[]): T[] {
  return arr.filter((item, index) => arr.indexOf(item) === index);
}
```
**Typical cost:** O(n²) comparisons on a dense array because each `indexOf` scans the input.
**Space Complexity:** O(n) — to store the filtered array of unique items.

### 2.2 Using Filter with Index Check (Optimized)
The `Set` records values already visited while `filter` preserves the input order of the first occurrences.

**Optimized Example Code**:
```typescript
function removeDuplicates<T>(arr: T[]): T[] {
  const seen = new Set<T>();
  return arr.filter(item => {
    if (!seen.has(item)) {
      seen.add(item);
      return true;
    }
    return false;
  });
}
```
**Cost:** O(n) additional space; runtime depends on the engine's Set implementation.

### 3. Using a Map for Object Uniqueness
A `Map` can deduplicate records by a chosen key such as `id`. When an id repeats, this example keeps the last object value while retaining that key's first insertion position.

**Example Code**:
```typescript
interface CustomObject {
  id: number;
  name: string;
}

function removeDuplicates(arr: CustomObject[]): CustomObject[] {
  const unique = new Map<number, CustomObject>();
  arr.forEach(obj => unique.set(obj.id, obj));
  return Array.from(unique.values());
}
```
**Cost:** O(n) additional space; Map access is required to be sublinear on average by the language specification, with concrete performance left to the engine.

### 4.1 Using Reduce with an Accumulator
This variant uses `includes` (SameValueZero equality) to find prior values. It is a useful illustration of accumulation, though repeated scans make it quadratic on a dense array.

**Example Code**:
```typescript
function removeDuplicates<T>(arr: T[]): T[] {
  return arr.reduce((acc, current) => {
    if (!acc.includes(current)) {
      acc.push(current);
    }
    return acc;
  }, [] as T[]);
}
```
**Typical cost:** O(n²) comparisons on a dense array.
**Space Complexity:** O(n) — for the accumulator array without duplicates.

### 4.2 Using Reduce with an Accumulator (Optimized)
This variant keeps the accumulator example while using a `Set` for membership checks. As with the filter variant above, it preserves the first occurrence order and uses SameValueZero equality.

```typescript
function removeDuplicates<T>(arr: T[]): T[] {
  const seen = new Set<T>();
  return arr.reduce((acc, current) => {
    if (!seen.has(current)) {
      seen.add(current);
      acc.push(current);
    }
    return acc;
  }, [] as T[]);
}
```
**Cost:** O(n) additional space; Set access is sublinear on average by specification, with concrete performance left to the engine.

### 5.1 Using Sort and Reduce
Sorting groups equal finite numbers together, but changes their order. This version sorts the caller's array in place.

**Example Code**:
```typescript
function removeDuplicates(arr: number[]): number[] {
  return arr.sort((a, b) => a - b).reduce((acc, current) => {
    if (acc.length === 0 || acc[acc.length - 1] !== current) {
      acc.push(current);
    }
    return acc;
  }, [] as number[]);
}
```
**Cost:** Sorting is typically O(n log n), plus O(n) space for the result array. This numeric example assumes finite numbers; the comparator and `!==` test do not define useful NaN ordering/deduplication.

### 5.2 Using Sort and Reduce (with Comparator)
For values other than finite numbers, supply an ordering comparator and an equality test that agree about which values count as duplicates. This helper sorts a copy, then keeps one value from each adjacent equivalence group.

```typescript
function removeDuplicatesByComparator<T>(
  arr: T[],
  compare: (left: T, right: T) => number,
  same: (left: T, right: T) => boolean
): T[] {
  const result: T[] = [];
  for (const current of [...arr].sort(compare)) {
    if (result.length === 0 || !same(result[result.length - 1], current)) {
      result.push(current);
    }
  }
  return result;
}
```
The comparator must place equivalent values together; this helper does not infer an equality rule for arbitrary objects.

### 6. Using ES6 `from` Method
`Array.from(new Set(arr))` has the same deduplication semantics as the spread form when an explicit constructor call is clearer.

```typescript
function removeDuplicates<T>(arr: T[]): T[] {
  return Array.from(new Set(arr));
}
```

## Find Max Number in a List
These variants assume a non-empty dense array of finite numbers. Spread and `apply` pass every element as a function argument, so very wide inputs can exceed an engine's argument limit. The `sort` variant mutates its input.
### Method 1: Using Spread Operator with `Math.max`

**Code**:
```ts
function findMaxNumber(arr: number[]): number {
  return Math.max(...arr);
}
```

**Explanation**:
- Utilizes the spread operator `...` to expand the array elements as individual arguments to `Math.max`.
- Simple and clean, but may exceed the engine's argument limit with very large arrays.

### Method 2: Using `Math.max` with `apply`

**Code**:
```ts
function findMaxNumber(arr: number[]): number {
  return Math.max.apply(null, arr);
}
```

**Explanation**:
- Uses the same argument-list approach through `apply`; it has the same empty-input and wide-input considerations as spread.

### Method 3: Using `reduce` Method

**Code**:
```ts
function findMaxNumber(arr: number[]): number {
  return arr.reduce((acc, cur) => acc > cur ? acc : cur, arr[0]);
}
```

**Explanation**:
- Implements the `reduce` function to traverse the array and maintain the highest value found.
- Avoids creating one large argument list; the initializer starts with the first element, so the example expects a non-empty array.

### Method 4: Using `sort`

**Code**:
```ts
function findMaxNumber(arr: number[]): number {
  return arr.sort((a, b) => b - a)[0];
}
```

**Explanation**:
- Sorts the input in descending order and selects the first element. It changes the caller's array and is less efficient than a single scan; use it when the sorted order is useful too.

## Spread Operator in JavaScript
The spread operator (`...`) allows an iterable such as an array to be expanded in places where zero or more arguments (for function calls) or elements (for array literals) are expected.

**Example Code in TypeScript:**
```ts
const baseArray = [1, 2, 3, 4];
const array = [...baseArray];
```
### BabelJS Overview
**Babel** can transform syntax according to its configured target and plugins. There is no single output for array spread: a simple known-array case may use `concat`, while general iterable spread needs iterator-compatible behavior. A transform also does not by itself supply missing runtime APIs such as `Array.prototype.flat`.

## JavaScript Array Methods

**Concatenation**
- **Method:** `concat()`
- **Description:** Joins two or more arrays, returning a new array without altering the originals.
- **Example:**
  ```javascript
  const array1 = ['a', 'b', 'c'];
  const array2 = ['d', 'e', 'f'];
  const newArray = array1.concat(array2);
  console.log(newArray);  // Output: ['a', 'b', 'c', 'd', 'e', 'f']
  ```

**Element Checking**
- **Methods:**
  - `every()`: Tests whether all elements in the array pass the provided function.
  - `some()`: Tests whether any element in the array passes the provided function.
- **Examples:**
  ```javascript
  const isBelowThreshold = (currentValue) => currentValue < 40;
  const array1 = [1, 30, 39, 29, 10, 13];
  console.log(array1.every(isBelowThreshold)); // Output: true
  console.log(array1.some(isBelowThreshold));  // Output: true
  ```

**Filtering**
- **Method:** `filter()`
- **Description:** Creates a new array with all elements that pass the test implemented by the provided function.
- **Example:**
  ```javascript
  const words = ['spray', 'limit', 'elite', 'exuberant', 'destruction', 'present'];
  const result = words.filter(word => word.length > 6);
  console.log(result);  // Output: ['exuberant', 'destruction', 'present']
  ```

**Mapping**
- **Method:** `map()`
- **Description:** Creates a new array populated with the results of calling a provided function on each present element in the calling array; holes are skipped.
- **Example:**
  ```javascript
  const numbers = [1, 4, 9, 16];
  const roots = numbers.map(Math.sqrt);
  console.log(roots);  // Output: [1, 2, 3, 4]
  ```

**Sorting**
- **Method:** `sort()`
- **Description:** Sorts the array in place and returns it. Without a comparator, values are sorted by string form; with a comparator, its result defines the order. Sorting has been stable since ECMAScript 2019.
- **Example:**
  ```javascript
  const months = ['March', 'Jan', 'Feb', 'Dec'];
  months.sort();
  console.log(months);  // Output: ['Dec', 'Feb', 'Jan', 'March']
  const numbers = [10, 2, 1];
  numbers.sort((a, b) => a - b);
  console.log(numbers); // Output: [1, 2, 10]
  ```

**Reversing**
- **Method:** `reverse()`
- **Description:** Reverses the array in place. The first array element becomes the last, and the last array element becomes the first.
- **Example:**
  ```javascript
  const array1 = ['one', 'two', 'three'];
  array1.reverse();
  console.log(array1);  // Output: ['three', 'two', 'one']
  ```

**Conversion to String**
- **Method:** `toString()`
- **Description:** Converts an array to a string of comma-separated array values.
- **Example:**
  ```javascript
  const array1 = [1, 2, 'a', '1a'];
  console.log(array1.toString());  // Output: '1,2,a,1a'
  ```

**Index Finding**
- **Methods:**
  - `indexOf()`: Returns the first index at which a given element can be found in the array, or -1 if it is not present.
  - `lastIndexOf()`: Returns the last index at which a given element can be found in the array, or -1 if it is not present.
- **Examples:**
  ```javascript
  const beasts = ['ant', 'bison', 'camel', 'duck', 'bison'];
  console.log(beasts.indexOf('bison'));        // Output: 1
  console.log(beasts.lastIndexOf('bison'));   // Output: 4
  ```

## Remove indicated elements from a list

### Functional Approach Using `filter`
```js
const removeElements = (arr, ...args) => arr.filter(item => !args.includes(item));
```
**Advantages**:
- **Immutability**: The original array remains unchanged.
- **Declarative**: Easy to read and understand.

**Disadvantages**:
- **Performance**: Using `includes` within `filter` can lead to quadratic time complexity (O(n*m)), where `n` is the length of `arr` and `m` is the length of `args`.

### Iterative Approach Using `forEach` and `splice`
Despite the retained historical heading, the implementation uses a `while` loop. It modifies the array in place and keeps the same index after `splice` removes an element, so adjacent matches are not skipped.

```js
const removeElements = (arr, ...args) => {
    let i = 0;
    while (i < arr.length) {
        if (args.includes(arr[i])) {
            arr.splice(i, 1);
        } else {
            i++;
        }
    }
    return arr;
}
```
**Advantages**:
- Avoids allocating a second result array.

**Disadvantages**:
- **Mutability**: Modifies the original array, which can lead to side effects.
- **Complexity**: Repeated removals shift remaining elements and can make the overall work quadratic.

### Optimized Approach Using `Set`
When `args` is large, a `Set` avoids scanning it for each input element. Set access is sublinear on average by specification, but an exact constant-time guarantee is not part of the language contract.

```js
const removeElements = (arr, ...args) => {
    const toRemove = new Set(args);
    return arr.filter(item => !toRemove.has(item));
}
```
**Advantages**:
- **Performance**: Often suitable for larger removal lists; actual costs depend on the engine.
- **Clarity and Safety**: Combines the clarity of the functional approach with the performance of using a `Set`.
