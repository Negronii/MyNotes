# Lodash Reference / Lodash参考

This page is scoped to Lodash 4.17.21, the version used by the checked API reference. Verify contracts against the version installed in a project, especially when moving between major versions.

**Core answer / 核心回答：** Lodash supplies focused helpers for arrays, collections, object paths, strings, and timed calls. Pay attention to whether a method mutates its input and to the exact fallback or scheduling behavior before replacing it with a native expression. / Lodash 为数组、集合、对象路径、字符串和定时调用提供专门工具。替换为原生表达式前，要先确认方法是否修改输入，以及默认值或调度行为的具体语义。

## Arrays / 数组

| Signature | Behavior |
|---|---|
| **_.chunk(array, size = 1)** | Split into consecutive groups of at most size items. |
| **_.compact(array)** | Remove falsey values such as false, null, 0, empty string, undefined, and NaN. |
| **_.concat(array, ...values)** | Return a new, shallowly concatenated array; nested arrays passed as values remain nested. |
| **_.difference(array, values)** | Return values from the first array that are absent from the other array. |
| **_.drop(array, n = 1)** | Return a slice after dropping the first n elements. |
| **_.intersection(...arrays)** | Return unique values from the first array that occur in every other array. |
| **_.flatten(array)** | Flatten one array level. |
| **_.flattenDeep(array)** | Flatten nested arrays recursively. |

~~~javascript
_.chunk(['a', 'b', 'c', 'd'], 2);
// [['a', 'b'], ['c', 'd']]

_.compact([0, 1, false, 2, '', 3]);
// [1, 2, 3]

_.concat([1], 2, [3], [[4]]);
// [1, 2, 3, [4]]

_.difference([2, 1], [2, 3]);
// [1]

_.intersection([2, 1, 2], [2, 3]);
// [2]
~~~

Native comparison: Array.prototype.flat() flattens one level by default; array.flat(Infinity) recursively flattens. Lodash flatten and flattenDeep express those two depths.

## Collections / 集合

| Signature | Behavior |
|---|---|
| **_.each(collection, iteratee)** | Visit collection values; return the original collection. It also has the _.forEach alias. |
| **_.filter(collection, predicate)** | Return all values for which the predicate is truthy. |
| **_.find(collection, predicate, fromIndex = 0)** | Return the first matching value, or undefined if none matches. |
| **_.map(collection, iteratee)** | Return an array of transformed values. |
| **_.reduce(collection, iteratee, accumulator)** | Fold values into an accumulated result. |
| **_.groupBy(collection, iteratee)** | Group values into object properties named by the iteratee result. |
| **_.orderBy(collection, iteratees, orders)** | Return a sorted array using one or more iteratees and asc/desc order entries. |

~~~javascript
const users = [
  { user: 'barney', age: 36, active: true },
  { user: 'fred', age: 40, active: false },
];

_.filter(users, user => !user.active);
// [{ user: 'fred', age: 40, active: false }]

_.groupBy([6.1, 4.2, 6.3], Math.floor);
// { '4': [4.2], '6': [6.1, 6.3] }

_.orderBy(users, ['age'], ['desc']).map(user => user.user);
// ['fred', 'barney']
~~~

## Objects and paths / 对象与路径

| Signature | Behavior |
|---|---|
| **_.assign(object, ...sources)** | Copy own enumerable string-keyed properties shallowly into object; mutate and return object. |
| **_.get(object, path, defaultValue)** | Read a nested path; use defaultValue only when the resolved value is undefined. |
| **_.keys(object)** | Return own enumerable string-keyed property names. |
| **_.merge(object, ...sources)** | Recursively merge source properties into object; mutate and return object. |
| **_.omit(object, paths)** | Return an object without the selected property paths. |

~~~javascript
const record = { a: [{ b: { c: 3 } }] };

_.get(record, 'a[0].b.c');
// 3

_.get({ value: null }, 'value', 'fallback');
// null

_.get({}, 'value', 'fallback');
// 'fallback'
~~~

The default-value distinction matters: _.get falls back for an absent path or an undefined value, but preserves null. The nullish-coalescing operator returns the right side for either null or undefined.

Both _.assign and _.merge mutate their first argument. assign copies only the top-level properties; merge recursively combines arrays and plain objects. When two arrays meet at the same property, merge combines their entries by index rather than concatenating them. Pass a fresh destination when the source objects should remain unchanged.

~~~javascript
const target = { a: [{ b: 2 }, { d: 4 }] };
const source = { a: [{ c: 3 }, { e: 5 }] };

const result = _.merge({}, target, source);
// result.a is [{ b: 2, c: 3 }, { d: 4, e: 5 }]
// target and source are unchanged; _.merge mutated the fresh destination.
~~~

Lodash also provides _.clone for a shallow copy and _.cloneDeep for a recursive copy. A shallow copy keeps nested object references shared; a deep copy recursively copies nested values supported by Lodash.

~~~javascript
const original = { nested: { count: 1 } };
const shallow = _.clone(original);
const deep = _.cloneDeep(original);

shallow.nested === original.nested; // true
deep.nested === original.nested; // false
~~~

Some other Lodash array methods mutate their input, including _.pull, _.remove, and _.reverse. Check the individual contract before using a result as immutable state.

## Strings and small utilities / 字符串与小工具

| Function | Example result |
|---|---|
| **_.camelCase('Foo Bar')** | fooBar |
| **_.capitalize('FRED')** | Fred |
| **_.kebabCase('Foo Bar')** | foo-bar |
| **_.snakeCase('Foo Bar')** | foo_bar |
| **_.startCase('fooBar')** | Foo Bar |
| **_.identity(value)** | Return the same value. |
| **_.times(n, iteratee)** | Invoke an iteratee n times and return the result array. |
| **_.uniqueId(prefix)** | Produce an identifier from Lodash's incrementing counter with an optional prefix; not a security token or a cross-process uniqueness guarantee. |

~~~javascript
_.times(3, String);
// ['0', '1', '2']

_.uniqueId('contact_');
// A string such as 'contact_1'; the counter depends on prior calls in this runtime.
~~~

## Debounce and throttle / 防抖与节流

Both functions return a wrapper with timer controls. Debounce consolidates calls around a quiet interval; throttle limits calls across an interval. Their exact leading and trailing behavior depends on the options.

| Signature | Behavior |
|---|---|
| **_.debounce(func, wait = 0, options)** | Delay invocation until calls have paused for the wait interval; optional leading, trailing, and maxWait behavior. |
| **_.throttle(func, wait = 0, options)** | Invoke at most once per wait interval, with optional leading and trailing calls. |

~~~javascript
const saveLater = _.debounce(saveDraft, 300);
saveLater();
saveLater.cancel(); // Discard a pending trailing call.
saveLater.flush();  // Invoke a pending trailing call immediately.

const refreshLimited = _.throttle(refresh, 1000);
refreshLimited.cancel();
refreshLimited.flush();
~~~

Use debounce for work that should follow a pause, such as a search request after typing. Use throttle for work that should run periodically during a stream of events, such as tracking scroll position. These are scheduling patterns, not network cancellation: cancelling a debounced callback does not cancel a request that has already started.
