# 文档冷读

## 作为作者

请一名未参与起草、也没看过写作讨论的读者从空白上下文开始。在 Codex 派 Subagent 时设 `fork_turns: "none"`。给读者实际要交付的版本，以及目标读者原本就有的背景。读者若会从特定链接或引言进入文档，也可以给实际的入口文字。写作提纲、预期结论和你担心哪里写得不好，留给作者自己。

收到反馈后，优先修改会让读者猜错含义、漏掉条件或采取错误行动的地方。由作者核对事实和内容完整性。若重要段落改写后仍需确认，可请同一读者复读改处。报告时称为复读。

## 作为读者

先看标题和开头，记下你以为下文会回答的问题。按目标读者平时的方式顺读正文，先靠成稿本身理解主线。遇到明确要求读者跳转才能完成的操作，可按文中的入口继续。

用自己的话说出你读到的主要意思、适用条件或下一步行动。遇到需要猜或回读的地方，引用具体措辞，说明当时把它理解成了什么、哪个指代找不到对象，或缺了哪一步才能跟上。读来生硬的表达也可以指出，给出更自然的说法时保留原意。读得顺畅时照实说。将观察直接交还作者。
