### AI engineering / AI 工程

- [Model Selection and Ecosystem / 模型选择与生态](../ai-engineering/foundations/model-selection-and-ecosystem.md) retains task-scoped model selection, hosted/open-weight/hybrid tradeoffs, routing, and modality constraints while removing stale catalogs and universal price or ranking rules. The note cites [OpenAI model optimization](https://developers.openai.com/api/docs/guides/model-optimization) and the changing [OpenAI models documentation](https://developers.openai.com/api/docs/models).
- [Prompt Engineering Fundamentals / 提示工程基础](../ai-engineering/prompting/prompt-engineering-fundamentals.md) explains useful prompt context and output contracts, and separates prompt guidance from application-side authorization and validation. Its examples are synthetic. The note cites [OpenAI prompt guidance](https://developers.openai.com/api/docs/guides/model-optimization#write-effective-prompts) and [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).
- [How LLMs Work / 大语言模型如何工作](../ai-engineering/foundations/how-llms-work.md) explains subword tokenization and common Transformer mechanisms while scoping autoregressive generation and BERT's adapted sampling procedure. Sources include the [Transformer paper](https://arxiv.org/abs/1706.03762), [subword units](https://arxiv.org/abs/1508.07909), and [BERT generation](https://arxiv.org/abs/1902.04094).
- [Advanced Prompting Techniques / 高级提示技巧](../ai-engineering/prompting/advanced-prompting-techniques.md) includes synthetic prompt-generation and failure-driven revision templates tied to held-out evaluation, and scopes reasoning, self-consistency, and tool-use techniques. Sources include [Automatic Prompt Engineer](https://arxiv.org/abs/2211.01910), [self-consistency](https://arxiv.org/abs/2203.11171), and [ReAct](https://arxiv.org/abs/2210.03629).
- [Fine-tuning Strategies / 微调策略](../ai-engineering/fine-tuning/fine-tuning-strategies.md) distinguishes parameter-efficient methods and preference tuning, explains training controls and validation, and marks provider-specific fine-tuning availability as time-sensitive. Sources include [LoRA](https://arxiv.org/abs/2106.09685), [DPO](https://arxiv.org/abs/2305.18290), and current [OpenAI deprecation guidance](https://developers.openai.com/api/docs/deprecations).
- [AI Application Architecture / AI 应用架构](../ai-engineering/systems/ai-application-architecture.md) explains quantization and distillation tradeoffs, inference batching versus asynchronous batch jobs, and the distinction between prompt caching and application response caching. Sources include [GPTQ](https://arxiv.org/abs/2210.17323), [knowledge distillation](https://arxiv.org/abs/1503.02531), and [Orca](https://www.usenix.org/conference/osdi22/presentation/yu).
- [AI System Design Interview Questions / AI 系统设计面试题](../ai-engineering/systems/ai-system-design-interview-questions.md) restores worked, explicitly hypothetical design choices and a checked capacity calculation, with stated trust and tool boundaries. Sources include the [RAG paper](https://arxiv.org/abs/2005.11401), [function calling](https://developers.openai.com/api/docs/guides/function-calling), and [Little's Law](https://doi.org/10.1287/opre.9.3.383).

### Frontend / 前端

- [Virtual DOM and Framework Selection / 虚拟DOM与框架选择](../frontend/frameworks/virtual-dom-and-framework-selection.md) explains reconciliation, component identity, and practical framework-selection factors without promising a universal speed advantage or framework ranking. Sources include [React Render and Commit](https://react.dev/learn/render-and-commit), [React Preserving and Resetting State](https://react.dev/learn/preserving-and-resetting-state), and the [Vue rendering mechanism](https://vuejs.org/guide/extras/rendering-mechanism).
- [Advanced TypeScript / TypeScript进阶](../frontend/typescript/advanced-typescript.md) keeps utility and generic relationships, Proxy behavior, TypeScript 5 standard decorators versus legacy decorators, and exhaustive union checking. Sources include [TypeScript utility types](https://www.typescriptlang.org/docs/handbook/utility-types.html), [generics](https://www.typescriptlang.org/docs/handbook/2/generics.html), and [TypeScript 5.0 decorators](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-5-0.html#decorators).
- [JavaScript Arrays / JavaScript 数组](../frontend/javascript/arrays.md) distinguishes iteration from property enumeration, sparse-array behavior across methods, mutation from copying, and flattening tradeoffs. Sources include the [ECMAScript indexed collections specification](https://tc39.es/ecma262/2025/multipage/indexed-collections.html) and [keyed collections specification](https://tc39.es/ecma262/2025/multipage/keyed-collections.html).
- [JavaScript Memory, WeakMap, WeakSet, and WeakRef / JavaScript 内存、WeakMap、WeakSet 与 WeakRef](../frontend/javascript/javascript-memory-weakmap-and-weakset.md) explains weak-key reachability, non-enumerability, supported weak keys, and why collection and finalization timing cannot be relied upon. Sources include [ECMAScript WeakMap](https://tc39.es/ecma262/2025/multipage/keyed-collections.html#sec-weakmap-objects) and [weak references and finalization](https://tc39.es/ecma262/2025/multipage/managing-memory.html).
- [Map and Set in JavaScript / JavaScript 中的 Map 与 Set](../frontend/javascript/map-and-set.md) covers collection choice, SameValueZero, identity and insertion order, ES2025 Set composition, and implementation-dependent complexity. Sources include the [ECMAScript keyed collections specification](https://tc39.es/ecma262/2025/multipage/keyed-collections.html) and its [Set methods](https://tc39.es/ecma262/2025/multipage/keyed-collections.html#sec-set-objects).
- [Browser Basics / 浏览器基础](../frontend/browser/browser-basics.md) explains the common fetch-to-presentation stages while qualifying engine-specific internals, script scheduling, and CORS behavior. Sources include the [HTML scripting standard](https://html.spec.whatwg.org/multipage/scripting.html#the-script-element), [Fetch CORS protocol](https://fetch.spec.whatwg.org/#http-cors-protocol), and [Chrome RenderingNG architecture](https://developer.chrome.com/docs/chromium/renderingng-architecture).
- [Image Lazy Loading / 浏览器图片懒加载](../frontend/browser-apis/image-lazy-loading.md) distinguishes native lazy loading from custom `IntersectionObserver` scheduling, including real image-source requirements and intersection edge cases. Sources include [WHATWG lazy-loading attributes](https://html.spec.whatwg.org/multipage/urls-and-fetching.html#lazy-loading-attributes), [Intersection Observer](https://www.w3.org/TR/intersection-observer/), and [CSSOM View geometry](https://www.w3.org/TR/cssom-view-1/).
- [Box Model and BFC / 盒模型与块格式化上下文](../frontend/html-css/box-model-and-bfc.md) separates box sizing and block-formatting-context float/margin behavior from stacking contexts and general containment. Sources include [CSS Display formatting contexts](https://www.w3.org/TR/css-display-3/) and [CSS 2.2 box dimensions](https://www.w3.org/TR/CSS22/box.html#box-dimensions).
- [Browser HTML and CSS / 浏览器中的 HTML 与 CSS](../frontend/html-css/browser-html-and-css.md) covers script scheduling and the distinction among reflow, repaint, and compositing without assigning universal performance costs. Sources include the [HTML scripting standard](https://html.spec.whatwg.org/multipage/scripting.html#the-script-element), [CSS Display](https://www.w3.org/TR/css-display-3/), and [Chrome forced-reflow guidance](https://developer.chrome.com/docs/performance/insights/forced-reflow).
- [HTML and CSS Basics / HTML 与 CSS 基础](../frontend/html-css/html-and-css-basics.md) retains concise references for units, selectors and specificity, responsive layout, inheritance, text overflow, and semantic HTML. Sources include [CSS Values and Units](https://www.w3.org/TR/css-values/), [CSS Selectors](https://www.w3.org/TR/selectors-4/), and [WAI form labels](https://www.w3.org/WAI/tutorials/forms/labels/).
